# Internal Docs

Documentacion interna para mantener contexto operativo del proyecto sin depender de memoria conversacional.

- `architecture.md`: decisiones de arquitectura y limites del sistema
- `project_management.md`: alcance, prioridades y criterios de cierre
- `development.md`: convenciones de implementacion y deuda tecnica
- `devops.md`: entorno local, gitignore y flujos reproducibles
- `documentation.md`: estrategia de README, notebook y explicacion para musicos
