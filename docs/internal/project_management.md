# Project Management

## Active Goal

Publicar una base reproducible de analisis musical que pueda compartirse sin incluir archivos con copyright o assets privados.

## Definition Of Done For The Bach Case Study

- estructura de carpetas clara entre publico y privado
- score curado utilizable para los 6 preludios
- audio privado organizado por nombres canonicos
- notebook legible para musicos
- TODO y roadmap actualizados

## Current Risk Register

- calidad desigual del OMR
- cobertura limitada de `kern`
- variaciones editoriales entre fuentes abiertas
- posible confusion si se mezclan varias grabaciones en el corpus expresivo principal
