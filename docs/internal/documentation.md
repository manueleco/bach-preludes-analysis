# Documentation

## Audiences

- musicos con interes analitico
- desarrolladores que quieran extender el toolkit
- futuros colaboradores que quieran agregar nuevos corpus

## Documentation Layers

- `README.md`: orientacion general y arquitectura
- `notebooks/case_studies/<case_id>/`: recorrido guiado y narrativo del caso de estudio
- `TODO.md`: estado vivo del proyecto
- `docs/internal/`: memoria operativa y de decisiones

## Style Goal

Explicar resultados de forma musicalmente legible, sin depender de jerga de software cuando no aporte.
