# Musopen Reference Corpus

Usa esta carpeta para material simbolico derivado de Musopen.

## Uso previsto

- cubrir huecos de fuente abierta
- contrastar una lectura practica o editorial
- mantener trazabilidad de donde vino el material

## Cuidado

No todos los materiales de Musopen tienen la misma utilidad para armonia detallada; valida siempre contra el corpus curado.

## Estado Actual De Ingestion

El manifiesto y el script de ingestión ya apuntan a paginas reales de Musopen para `BWV 1007-1012`.

En este momento, la descarga automatica desde CLI queda bloqueada por un desafio de Cloudflare en las paginas y URLs de descarga. Por eso:

- el perfil queda documentado y trazable
- el script genera reporte
- pero la obtencion del PDF sigue requiriendo navegador interactivo cuando Musopen no libera acceso programatico
