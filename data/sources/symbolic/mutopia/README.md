# Mutopia Reference Corpus

Usa esta carpeta para exports simbolicos o MIDI procedentes de Mutopia.

## Uso previsto

- contraste editorial de una fuente abierta
- material de apoyo cuando falten otras transcripciones
- comparacion de estructura basica entre fuentes

## Recomendacion

Si descargas desde Mutopia, intenta convertir o exportar a `MusicXML` antes de promover nada al corpus oficial.
