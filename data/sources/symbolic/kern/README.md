# Kern Reference Corpus

Usa esta carpeta para copias locales en `**kern` de los preludios `BWV 1007-1012`.

## Uso previsto

- contraste estructural con el corpus curado
- pruebas de compatibilidad con `music21` y Humdrum
- revision de segmentacion y spelling

## Notas

- intenta dejar un archivo por preludio
- si el nombre viene raro, el paquete intentara mapearlo al ID canonico por `BWV`
- este corpus no sustituye `data/raw/`
