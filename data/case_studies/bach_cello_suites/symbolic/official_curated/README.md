# Official Curated Symbolic Corpus

Esta carpeta es el corpus simbolico oficial y publico del caso de estudio.

## Reglas

- aqui solo entran archivos listos para analisis
- preferir `MusicXML` o `MXL`
- si un archivo viene de OMR, debe revisarse musicalmente antes de entrar aqui
- esta es la carpeta que la CLI usa por defecto para armonia

## Resultado esperado

Los archivos deben seguir el nombre canonico del catalogo en:

`data/case_studies/bach_cello_suites/catalog/pieces.csv`
